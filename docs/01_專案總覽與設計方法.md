# 專案總覽與設計方法

## 1. 專案基本資訊

### 1.1 專案名稱
**LVGL Smart Motorcycle Dashboard Simulator (高階智慧機車儀表模擬器)**

### 1.2 開發環境
- **作業系統**: Linux (Ubuntu/Debian)
- **開發工具**: Visual Studio Code
- **編譯系統**: CMake 3.12.4+ 與 GCC
- **圖形庫**: LVGL v9.4.0-dev
- **顯示後端**: SDL2
- **字體渲染**: FreeType
- **RTOS**: FreeRTOS (可選)

### 1.3 專案目錄結構
```
/home/sshuser/LVGL/
├── CMakeLists.txt                    # CMake 建置設定檔
├── lv_conf.h                          # LVGL 組態檔
├── README.md                          # 專案說明文件
├── src/                               # 主要原始碼目錄
│   ├── main.c                         # 主程式進入點（非 FreeRTOS 模式）
│   ├── freertos_main.c                # FreeRTOS 主程式（RTOS 模式）
│   ├── ui_main_dashboard.c/h          # 主儀表板介面
│   ├── ui_settings_menu.c/h           # 設定選單介面
│   ├── ui_state_manager.c/h           # 狀態管理系統
│   ├── ui_dashboard_layouts.c/h       # 儀表板布局系統
│   ├── mouse_cursor_icon.c            # 滑鼠游標圖示
│   └── hal/                           # 硬體抽象層
│       └── hal.c/h                     # SDL2 HAL 實作
├── lvgl/                              # LVGL 圖形庫原始碼
├── FreeRTOS/                          # FreeRTOS 原始碼（可選）
├── config/                            # 組態檔案
│   └── FreeRTOSConfig.h               # FreeRTOS 組態
├── build/                             # CMake 建置輸出
└── bin/                               # 執行檔輸出
    └── main                           # 主執行檔
```

## 2. 程式設計方法

### 2.1 範例驅動開發 (Example-Driven Development)

本專案採用「**範例驅動開發**」策略，這是一種高效率的 UI 開發方法：

#### 開發流程
1. **鎖定功能**: 確定要實現的 UI 功能（如：轉速表、滑動條、選單）
2. **定位範例**: 在 LVGL 官方 `lvgl/examples` 目錄中找到最接近的範例
3. **拆解與修改**: 複製範例程式碼，理解其構成，修改參數、樣式、事件處理
4. **整合測試**: 將修改後的程式碼整合到專案中，確保編譯與運行正常
5. **客製化優化**: 根據專案需求進一步優化介面與互動邏輯

#### 範例參考對照表
| 功能 | 參考範例 | 原始檔位置 |
|------|---------|-----------|
| 轉速表/儀表盤 | `lv_example_meter_4.c` | `lvgl/examples/widgets/meter/` |
| 下拉選單 | `lv_example_dropdown_1.c` | `lvgl/examples/widgets/dropdown/` |
| 滑動條 | `lv_example_slider_1.c` | `lvgl/examples/widgets/slider/` |

| Flex 佈局 | `lv_example_flex_1.c` | `lvgl/examples/layouts/flex/` |

### 2.2 模組化設計原則

#### 分層架構
```
┌─────────────────────────────────────┐
│     UI 層 (Presentation Layer)       │
│  - ui_main_dashboard.c               │
│  - ui_settings_menu.c                │
│  - ui_dashboard_layouts.c            │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│   邏輯層 (Business Logic Layer)      │
│  - ui_state_manager.c                │
│  - 狀態機、資料驗證、事件處理        │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│     HAL 層 (Hardware Abstraction)    │
│  - hal.c (SDL2 封裝)                 │
│  - 顯示、輸入、計時器                │
└─────────────────────────────────────┘
```

#### 模組職責
- **UI 層**: 負責畫面繪製、佈局設計、視覺效果
- **邏輯層**: 負責狀態管理、資料計算、事件回應
- **HAL 層**: 負責硬體抽象、SDL2 整合、輸入輸出

### 2.3 設計模式應用

#### 狀態管理模式
使用全域狀態結構 `VehicleState_t` 集中管理所有車輛資料：
```c
typedef struct {
    int current_rpm;        // 當前轉速
    int target_rpm;         // 目標轉速
    int current_speed;      // 當前時速
    int current_gear;       // 當前檔位
    int riding_mode;        // 騎乘模式
    int tcs_level;          // 循跡控制等級
    int abs_level;          // ABS 等級
    int brightness;         // 螢幕亮度
    // ... 其他狀態
} VehicleState_t;
```

#### 事件驅動模式
所有 UI 互動透過 LVGL 事件系統處理：
```c
lv_obj_add_event_cb(btn, button_event_cb, LV_EVENT_CLICKED, NULL);
```

#### 計時器模式
使用 LVGL 計時器實現資料模擬與 UI 更新：
```c
lv_timer_t *timer = lv_timer_create(update_callback, 100, NULL);
```

## 3. 專案來源說明

### 3.1 基礎框架來源
本專案**基於 LVGL 官方提供的 PC 模擬器專案**：
- **原始專案**: [lvgl/lv_port_pc_vscode](https://github.com/lvgl/lv_port_pc_vscode)
- **授權**: MIT License
- **用途**: 提供 LVGL 在 PC 上的執行環境與 SDL2 整合

### 3.2 自行開發的部分
以下為**完全自行設計與實作**的模組：

#### ✅ 完全原創模組
1. **ui_main_dashboard.c/h** (主儀表板)
   - 儀表板整體佈局設計
   - 轉速表設計與動畫
   - 時速/檔位顯示
   - 油門/剎車控制面板
   - 主題切換功能

2. **ui_settings_menu.c/h** (設定選單)
   - 三層式選單架構
   - 騎乘模式選擇與切換邏輯
   - TCS/ABS 參數調整
   - 亮度與顯示設定
   - 模式變更警告對話框

3. **ui_state_manager.c/h** (狀態管理)
   - 車輛狀態結構設計
   - 物理模擬演算法（RPM、時速、檔位關係）
   - 輸入控制系統（油門、剎車、換檔）
   - 狀態驗證與錯誤處理
   - 資料模擬計時器

4. **ui_dashboard_layouts.c/h** (布局系統)
   - Normal 雙環布局（轉速表 + 時速表）
   - Race 賽道布局（進度條式 RPM）
   - Offroad 越野布局
   - 布局動態切換機制

5. **main.c** (主程式整合)
   - 中文字體載入系統
   - 主程式初始化流程
   - 主迴圈設計

#### 🔄 修改與客製化的部分
1. **CMakeLists.txt**
   - 新增自定義原始檔編譯規則
   - FreeType 字體支援整合
   - 優化編譯選項

2. **lv_conf.h**
   - 調整記憶體配置（1MB heap）
   - 啟用 FreeType 字體渲染
   - 調整顯示刷新率

3. **hal.c** (僅微調)
   - 視窗尺寸調整為 800x600
   - 滑鼠游標整合

#### 📦 直接使用的第三方組件
1. **LVGL 圖形庫** (lvgl/)
   - 核心圖形引擎
   - Widget 組件
   - 官方範例程式碼

2. **SDL2 HAL 實作** (src/hal/hal.c)
   - 原 lv_port_pc_vscode 提供的 SDL2 封裝
   - 僅微調視窗參數

3. **滑鼠游標圖示** (mouse_cursor_icon.c)
   - 原專案提供的預設游標

### 3.3 程式碼比例估算
- **原創開發**: 約 75%（約 2800+ 行程式碼）
- **修改客製**: 約 15%（約 300 行程式碼）

## 4. 核心技術亮點

### 4.1 中文字體整合
使用 FreeType 動態載入系統字體：
```c
g_chinese_font = lv_freetype_font_create(
    "/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc",
    LV_FREETYPE_FONT_RENDER_MODE_BITMAP,
    16,
    LV_FREETYPE_FONT_STYLE_NORMAL
);
```

### 4.2 物理模擬演算法
實現摩托車動力學模型：
- **RPM 與時速關係**: 根據檔位和齒輪比計算
- **換檔邏輯**: 升檔/降檔時保持時速，自動調整 RPM
- **油門/剎車響應**: 模擬真實車輛的加速/減速特性

### 4.3 主題系統
支援深色/淺色主題動態切換：
- 自動調整所有 UI 元件顏色
- 針對不同模式優化對比度
- 平滑的主題過渡效果

### 4.4 多層次選單系統
實現三層式導航架構：
- 主選單 → 子選單 → 詳細設定
- 返回鍵支援階層式導航
- 麵包屑導航提示
